Results status bar — design reference

Permanent bar that sits above the exhibition list. Always shows shown/total counts. The reset button appears only when filters are active.

State A — no filters active (button hidden)

Näytetään 48 / 48 näyttelyä

State B — filters active (button visible)

Näytetään 7 / 48 näyttelyä

State C — filters active, zero matches (bar persists)

Näytetään 0 / 48 näyttelyä
